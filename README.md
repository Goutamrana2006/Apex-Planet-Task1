# PHP Project – Sum of Two Numbers

## 📌 Project Overview

This project is a simple web application developed using **HTML and PHP** as part of my Web Development Internship at **ApexPlanet Software Pvt. Ltd.** It allows users to enter two numbers through an HTML form and calculates their sum using PHP.

## 🎯 Features

* User-friendly HTML form.
* Accepts two numeric inputs.
* Processes form data using the HTTP POST method.
* Calculates the sum of two numbers using PHP.
* Displays the result dynamically on the webpage.
* Basic input validation using HTML's `required` attribute.

## 🛠️ Technologies Used

* **HTML5** – For creating the web form and page structure.
* **PHP** – For server-side processing and addition.
* **XAMPP** – For running the application locally using Apache.
* **Visual Studio Code** – For writing and editing code.

## 📂 Project Structure

```text
Sum-of-Two-Numbers/
│
├── index.html    # HTML form for entering two numbers
├── index.php     # PHP logic for calculating the sum
└── README.md     # Project documentation
```

## ⚙️ How to Run the Project

1. Install and open XAMPP.

2. Start the **Apache** server.

3. Copy the project folder into the `htdocs` directory.

4. Open your web browser.

5. Visit the following URL:

   `http://localhost/ApexPlanet-Task1/index.html`

6. Enter the first and second numbers.

7. Click the **Submit** button to view the calculated sum.

## 💻 How It Works

1. The user enters two numbers in the HTML form.
2. The form sends the values to `index.php` using the POST method.
3. PHP retrieves the values using the `$_POST` superglobal.
4. The `+` operator calculates the sum.
5. The result is displayed on the webpage using `echo`.
